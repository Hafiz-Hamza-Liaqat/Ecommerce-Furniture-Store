# RC10.3 — Budget Recalculation Report

**Status:** Implemented — awaiting manual review  
**Date:** 2026-07-21

## Line math

```ts
lineUnitPrice(line) = unitPriceForSelection(line.product, line.variantIds ?? [])
total = Σ lineUnitPrice(l) * l.qty
```

Qty edits, variant changes, product swaps, and remove all flow through the same total.

## `applyPackageLines`

Central mutate path for package line edits:

1. Marks package customized (when bump requested)
2. `setLines(nextLines)`
3. Persists room snapshot with configured `unitPkr` + optional `variantIds`

`applyConfiguredLine` patches one line (product / variants / enrichments) then calls `applyPackageLines`.

## Live utilization

Result header recomputes on every lines/budget change:

- Package total (`formatPkr(total)`)
- Utilization **percent** vs brief budget
- Remaining budget
- Utilization bar width (`min(100, percent)%`)

No separate pricing engine — planner UI stays the source of truth for configured totals.
