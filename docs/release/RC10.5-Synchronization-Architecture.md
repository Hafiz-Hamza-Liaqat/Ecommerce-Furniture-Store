# RC10.5 — Synchronization Architecture

- **Status:** Implemented — awaiting manual review (no commit)
- **Model:** Local-primary CX workspace with cloud snapshot sync
- **APIs:** `GET/PUT /api/v1/cx/workspace` (session-scoped; first CX cloud APIs)

## Principles

1. Domain models unchanged — sync transports opaque `localStorage` payloads.
2. Local cache remains the working set; cloud is the multi-device mirror.
3. Authenticated users only; no RBAC catalog changes (own-user blob).
4. No real-time collaboration (hooks reserved for RC10.6+).

## Syncable surfaces

Projects, planner, consultant memory, leads queue, wishlist/compare/recent, notifications, catalog gaps, sales workspace (CRM/orders/quotes/timeline), user prefs.

## Components

| Layer | Path |
|---|---|
| Engine | `packages/web/src/marketing/cx/sync/` |
| Status UI | `SyncStatusChip` in TopBar + MarketingShell |
| HTTP remote | `ApiClient.getCxWorkspace` / `putCxWorkspace` |
| Local-cloud fallback | `afh.cloud.cx.v1.{userId}` |
| Server store | `packages/api/src/cx-sync/` → `data/cx-sync/` |

## Collaboration extension points

`registerCollaborationHooks` accepts shared-project / team / presence / live-edit callbacks — **not invoked** in RC10.5.
