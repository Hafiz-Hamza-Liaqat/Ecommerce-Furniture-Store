# RC10.5 — Sync Engine Report

## Capabilities

- Initial full sync + incremental dirty detection (content hash per key)
- Outbox queue (`afh.cx.sync.outbox`) while offline / HTTP failure
- Automatic retry on online, login, 60s interval, Sync Now
- Resilient remote: HTTP preferred, local-cloud always mirrored
- Prevents duplicate keys by merging on record `key`

## Triggers

- Application startup (authenticated session)
- Authentication / session bootstrap
- `online` event
- Periodic background interval (60s)
- Manual **Sync Now**
- Cross-tab `storage` events on cloud mirror

## Integrity

Stable record keys; quotation / order / CRM histories remain append-only in their domain stores. Sync never rewrites planner calculation code.
