# RC10.3 — Catalog Gap Report

**Status:** Implemented — awaiting manual review  
**Date:** 2026-07-21

## Storage

| Key | API |
|-----|-----|
| `afh.cx.catalogGaps` | `recordCatalogGap` / `listCatalogGaps` / `clearCatalogGaps` |

Records: role, optional `templateId`, `requiredQty`, `availableCount`, computed `gap`, `recordedAt`. Cap ~200 rows. Ops side-channel — **no** customer-facing gap browser in RC10.3.

## Conceptual CTAs

When optimize yields `conceptual` lines (no catalogue SKU):

- Copy: “No exact catalog match” / “We can manufacture…”
- **Request Custom Manufacturing** — records gaps + queues CRM lead
- **Request Sales Consultation** — sales path without inventing products

Empty change-product drawer offers the same custom / consult CTAs.

## Never invent SKUs

Alternatives and replacements are catalogue IDs only (`listCompatibleAlternatives` asserts IDs ∈ `CATALOGUE`). Conceptual roles stay notes + manufacturing CTAs — never fake product rows.
