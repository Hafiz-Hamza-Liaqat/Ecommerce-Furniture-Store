# RC10.4 — Operational Analytics Report

Dashboard KPIs from `computeOperationalMetrics` (operational only; advanced BI remains RC10.6):

| Metric | Definition |
|---|---|
| Open quotations | draft / sent / viewed |
| Conversion rate | accepted / (accepted + rejected) |
| Orders in production | status = in_production |
| Average quotation value | mean of all sales quote totals |
| Pending approvals | orders awaiting_approval |
| Accepted revenue | sum of accepted quote totals |
| Upcoming deliveries | ready_for_delivery or scheduled |

Also lists: recent inquiries, pending quotations, approval queue, production queue, upcoming deliveries.
