# RC10.7 — Stock Movement Report

## Types

| Type | Effect |
|---|---|
| `purchase_received` | + on-hand (PO receive) |
| `production_allocation` | + reserved |
| `production_consumption` | − on-hand, − reserved |
| `allocation_release` | − reserved (pre-production release) |
| `manual_adjustment` | + on-hand (positive adjust) |
| `correction` | − on-hand (negative adjust; blocked if would go negative) |
| `return` | + on-hand |

## History

Movements prepended (newest first), capped at 2000. Movements tab lists type, SKU, qty/reserved deltas, timestamp, note, optional ref.

All mutations go through `applyMovement` → `assertNonNegative`.
