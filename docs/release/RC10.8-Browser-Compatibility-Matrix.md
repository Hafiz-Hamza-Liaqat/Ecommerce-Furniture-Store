## Console allowlist

| Pattern | Reason |
|---|---|
| Vite HMR / `[vite]` messages | Dev-server tooling |
| Vite websocket to `localhost` / `127.0.0.1` | Dev-server tooling |
| React DevTools download banner | Informational |
| Firefox “Layout was forced…” | Engine advisory during rapid automation |
| Firefox font glyph/fallback advisories | Fallback behavior; fonts still load |
| Unsupported `PerformanceObserver` entryTypes | Feature-detected advisory |
| `InstallTrigger is deprecated` | Firefox platform notice |
| “Loading failed for the module with source …” | Firefox analogue of aborted Vite module fetches during rapid SPA navigation |

Aborted network failures (`ERR_ABORTED`, `NS_BINDING_ABORTED`, cancelled loads) are counted separately and do not fail a route.
