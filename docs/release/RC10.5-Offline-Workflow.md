# RC10.5 — Offline Workflow

1. Local CX stores continue to accept writes while offline.
2. `markSyncDirty` / hash detection enqueue pending changes.
3. Sync status → **Offline** / **Pending changes**.
4. `OfflineBanner` shows queued change count.
5. On reconnect, `runSyncCycle` drains outbox and merges with cloud.
6. No intentional data loss — failed HTTP uploads keep local-cloud + outbox.
