# RC10.7 — Supplier Management

## Fields

Company, contact person, phone, email, address, categories supplied, performance notes, status (active/inactive).

## API

- `createSupplier` / `updateSupplier` / `listSuppliers`
- Inventory items and procurement requests reference `supplierId`
- Ops filters include supplier dropdown; searchOps filters items by `supplierId`

## UI

Suppliers tab: create + edit (including category assignment). Categories drive procurement context, not pricing.
