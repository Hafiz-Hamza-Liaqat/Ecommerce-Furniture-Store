## Production hygiene (secrets & data)

- Root `.gitignore` excludes runtime data: SQLite DBs, WAL/SHM, `cx-sync/`,
  `dam-objects/`, `backups/` — reduces risk of committing live data or secrets.
- `env.example` uses placeholders only; real secrets go to the secret manager.
- Backup script includes `cx-sync/` and `dam-objects/` and uses `sqlite3
  .backup` when available.

## Known accepted security risks

- **Rate limiting** is in-memory and single-node (not shared across replicas).
- **Tokens** are stored in `localStorage`.
- **MFA step-up** is incomplete; challenge delivery provider is not wired.
- **CSRF** is **N/A** under Bearer / `localStorage` auth. It would only become
  relevant if cookie-based sessions are introduced.
- **Safari / device** security-relevant behavior requires manual QA.
