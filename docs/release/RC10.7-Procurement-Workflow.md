# RC10.7 — Procurement Workflow

## Stages

Draft → Requested → Approved → Ordered → Received → Closed

Forward-only advances via `advanceProcurement` (index may not decrease).

## Model

- `supplierId`
- `lines[]` — `{ itemId, qtyOrdered, qtyReceived }`
- `expectedDelivery?`, `notes`, timestamps

## Receive

`receiveProcurement(id, receipts)`:

- Allowed when stage is `approved`, `ordered`, or `received` (partial)
- Caps qty to remaining ordered
- Posts `purchase_received` movements (+ on-hand)
- Sets stage to `received` when all lines fully received, otherwise `ordered`

UI **Receive all** calls receive only (does not double-advance).

## Closed

Operators advance to `closed` after receipt via stage select.
