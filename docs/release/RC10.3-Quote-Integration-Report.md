# RC10.3 — Quote Integration Report

**Status:** Implemented — awaiting manual review  
**Date:** 2026-07-21

## Configured unit prices

Downstream surfaces use `lineUnitPrice` (variant-aware), not bare catalogue base price:

| Surface | Behavior |
|---------|----------|
| `recordQuote` | Lines stored with `unitPkr: lineUnitPrice(l)` and package `totalPkr` |
| Export PDF | Row totals = `lineUnitPrice(l) * qty` |
| CRM lead | Meta includes configured `total` and line quantities/roles |
| Consultant handoff | `unitPkr` per line from `lineUnitPrice`; greeting uses configured package total |
| Project room snapshot | Persists configured `unitPkr` (+ `variantIds` when set) |

## Adjustments headroom

RC10.3 does **not** implement package discounts, promos, free delivery, or bundle pricing.

Quote / line payloads leave room for future additive adjustment slots (e.g. empty `adjustments[]`). Today there are **no** adjustment entries; existing `recordQuote` line shape remains valid when adjustments are absent.
