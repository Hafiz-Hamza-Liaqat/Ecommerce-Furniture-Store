# RC10.1 — Project Creation Fix Report

**Status:** Implemented — awaiting manual review (do not commit until approved)

## Issues

| # | Severity | Symptom |
|---|----------|---------|
| 1 | Blocker | New Project appeared as HTTP **500** (EnterpriseError `server` UI) |
| 2 | High | Every new project used the same title (`New furnishing project`) |

## Root cause (Blocker)

Project creation is **client-only** (`afh.cx.*` localStorage). There is no project-create API. The “500” was the app error boundary / broken planner continuity, not a backend HTTP 500.

**Primary bug:** `createProject({ owner: { ownerId: user.id }})` wrote `ownerId` as the signed-in user while `getLocalOwnerId()` could remain `guest-local` (merge-on-login race or never synced). `getProject(id)` then returned `null` because access checks require `ownerId === actorId`.

After redirect to `/planner?projectId=…`:

1. Planner restore exited early when `getProject` failed
2. `booting` could stick, or subsequent planner use of unloaded state failed
3. Storage write failures also bubbled uncaught → error boundary → code **500**

Secondary contributors:

- Owner collaborator row used a **random** `id` instead of `ownerId`
- Full page reload via `window.location.href` (harder recovery, duplicate boot work)
- Empty new projects set `restoredFromProject=true` with **zero lines**, blocking package line seeding

## Fixes

1. **`createProject`** always calls `setLocalOwnerId(ownerId)` before save; owner collaborator `id` = `ownerId`
2. **Storage writes** throw clear `Error` messages (quota / write failure) instead of opaque DOMExceptions
3. **Planner restore** recovers via `loadProject` + `setLocalOwnerId` when access lags; always clears booting; surfaces a clear load error; seeds package lines for empty rooms without wiping restored brief/budget
4. **Studio create** uses `navigate` (SPA) instead of full reload; create errors stay in the dialog (not swallowed)

## Naming / dialog (High)

Replaced instant auto-create with **New Project** dialog:

| Field | Required | Notes |
|-------|----------|--------|
| Project name | Yes | Trimmed, max 100 chars |
| Project type | No | Home, Office, Restaurant, Hotel, Hospital, School, Retail, Jahez, Custom |
| Short description | No | Stored as `plannerSummary` |
| Budget (PKR) | No | Applied to seed room brief |
| Location | No | Seed note `Location: …` |

- Cancel → no project created  
- Duplicate names allowed; unique internal UUID  
- Existing projects untouched
