## Defects found and fixed this cycle

### 1. API lint defect (fixed)
- **Where:** `packages/api/src/routes/routes.ts:77`
- **Issue:** inline `import()` type expression flagged by lint.
- **Fix:** replaced with a **type-only** `CxWorkspaceStore` import.
- **Verification:** `@afh/api` typecheck / lint / build / test re-run **PASS**
  (75 tests).

### 2. RC10.5 dual-browser harness (fixed)
- **Issue:** the dialog **Close** control rendered **outside the viewport**, so a
  coordinate-based click missed and the test failed initially.
- **Fix:** test harness updated to perform a **DOM click** on the control.
- **Verification:** dual-browser sync re-run **PASS**. This was a test-harness
  issue, not a product regression.

### 3. Authenticated accessibility defects (fixed)
- **Where:** top bar, KPI trend badge, and dashboard map controls.
- **Issue:** unnamed/mismatched button names, 4.18:1 trend contrast, and 12px
  interactive map pins.
- **Fix:** localized ARIA labels/hidden icon text, darker trend text, and 24px
  hit targets that preserve the visual marker.
- **Verification:** authenticated Lighthouse app shell **A88 → A96**; Workspace
  BI **A95 → A100**.
