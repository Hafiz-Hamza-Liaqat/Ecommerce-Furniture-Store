# RC10.7 — BOM Report

## Purpose

Bills of Materials define material quantities required to produce a furniture product inventory item.

## Model

- `productItemId` — finished good (inventory item)
- `label`
- `lines[]` — `{ itemId, qtyPerUnit }` for wood, hardware, fabric, foam, glass, metal, accessories, packaging, etc.

## API

- `createBom({ productItemId, label, lines })` — requires ≥1 line with `qtyPerUnit > 0`
- `updateBom(id, { label?, productItemId?, lines? })`
- `listBoms()`

## Production scaling

Job quantity × `qtyPerUnit` = required material. Allocation uses this formula in `computeAllocations`.

## Quotation isolation

BOM storage and services live only under `marketing/cx/ops`. Configurator / quotation engines are not imported or called. Unit test asserts sales workspace JSON is unchanged after BOM create/update.
