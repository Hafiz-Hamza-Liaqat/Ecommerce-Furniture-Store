# RC10.2.1 — Planner Stability Report

**Status:** Implemented — awaiting manual review (do not commit until approved)  
**Date:** 2026-07-21  
**Scope:** Bug fixes only · **Not RC10.3**

## Problem

AI package generation overwrote user Remove / quantity edits because the planner never entered a durable **User Customized** lock (`manualLines` stayed false).

## Fixes

### 1. Manual edit lock

- **Remove** and **Qty** call `markPackageCustomized`, setting `manualLines = true`
- Auto-regenerate uses `shouldAutoRegeneratePackage` — never runs while customized
- Discovery / flag / budget edits no longer exit customized mode (only Reset does)
- Programme template change does not clear customized mode

### 2. Reset to AI Package

- Button on package result header
- Clears customized state, regenerates from current `planFromBrief` result for the active tier
- Only exit path from User Customized mode

### 3. Planner status

- **AI Generated** vs **Customized by You**
- Optional manual change count when customized
- Short hint when locked

### 4. Explicitly not implemented (RC10.3)

Add Product · Change Product · Variants · Compatibility · Drawer · Re-ranking · Quote optimization

## Project continuity (separate)

See regression report. Exact screenshot copy (“Creating a new project… redirecting…”) was **not** in this codebase; planner now surfaces a clear inaccessible-ID error + Design Studio / new plan links, and runs `mergeProjectsOnLogin` + raw `loadProject` owner realign before access checks.
