# RC10.4 — CRM Workflow Report

- **Status:** Implemented — awaiting manual review (no commit)
- **Surface:** `/app/sales/workflow` (Sales → Sales workflow)
- **Persistence:** `afh.cx.sales.workspace` (local until RC10.5)

## Pipeline stages

New Inquiry → Qualified → Quotation Sent → Negotiation → Approved → Production → Ready for Delivery → Delivered → Closed

## Opportunity record

Each CRM opportunity preserves:

| Field | Source |
|---|---|
| Customer name / email / phone | Inquiry or quote form |
| Project link | `projectId` / title from planner |
| Package total & budget | Bridged from quote / brief |
| Quote & order ids | Sales quote / order collections |
| Assignments | Salesperson, designer, architect, PM |
| Stage | Pipeline stage enum |
| Activity | Customer timeline events |

## Bridges (no project model change)

- `enqueueLead` → `bridgeLeadToSales`
- `recordQuote` → `bridgeProjectQuoteToSales` (immutable sales revision; project quotes untouched)

## Notifications reused

- `crm_lead` on inquiry
- `quote_approved` / `quote_rejected` on quote status
- Existing `quotation_ready` from project `recordQuote`

## Constraints honored

Planner engine, configurator, auth, RC9.5 security, branding, and project persistence shape were not redesigned.
