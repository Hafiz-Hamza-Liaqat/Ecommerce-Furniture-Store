# RC10.3 — Variant System Report

**Status:** Implemented — awaiting manual review  
**Date:** 2026-07-21

## Groups

`groupVariants(product)` buckets `CatalogueProduct.variants[]` by `ProductVariant.group`:

`color` → `material` → `finish` → `dimensions` → `hardware` → `configuration` (+ any remaining groups).

Planner line UI renders one labeled `<select>` per group (`role="group"` aria-label “Variants”).

## Pricing

```ts
unitPriceForSelection(product, variantIds) → resolveVariantPrice(product, new Set(variantIds))
```

Base `pricePkr` plus selected variant deltas. Empty selection = base price.

## Persistence (`PlannerHandoffLine`)

Additive optional field on `PlannerHandoffLine`:

```ts
readonly variantIds?: readonly string[];
```

- Project room lines are `PlannerHandoffLine[]`; snapshots write `variantIds` when non-empty
- `restorePlannerFromRoom` / `planner-bridge` restore them into editable lines
- Configured `unitPkr` always reflects `unitPriceForSelection`

Variants stay under a product — they are not duplicate catalogue SKUs.
