# RC10.5 — Performance Report

- Sync uploads a **snapshot of changed records**, not a full browser dump of unrelated keys.
- Content hashes avoid bumping revisions when payloads are unchanged.
- Outbox dedupes by key (latest write wins per key).
- Periodic interval is 60s; no upload when idle and hashes match.
- Architecture ready for larger workspaces via per-key records (future: server-side delta endpoints).
