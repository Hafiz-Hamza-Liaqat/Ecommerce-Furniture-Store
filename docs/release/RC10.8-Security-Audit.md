## Authentication results

- Invalid credentials return 403 `invalid_credentials` without stack traces.
- Logout revokes the server session; subsequent bearer use fails.
- Refresh rotates the refresh token.
- Replaying a consumed refresh token returns an authorization error and
  revokes the session family (confirmed by requiring re-authentication before
  later authorized scenarios).
- MFA enable + password-only block (`mfa_required`) + challenged success +
  consumed challenge replay rejection all passed against a disposable
  activated account.
- Concurrent sessions remain allowed by design (no single-session lockout
  feature); family revoke applies on refresh reuse.

## Authorization results

- Unauthenticated register cannot bind `companyId`.
- Missing bearer on session / MFA / CX sync → 401/403.
- Guest deep link to `/admin/platform` redirects to login.
- CX sync stores snapshots under the authenticated user id only; path

## Injection results

### Confirmed and fixed

**P3-D1 — Planner HTML export XSS / HTML injection**

- Severity: High
- Component: `packages/web/src/marketing/pages/BudgetPlannerPage.tsx`
- Steps: Generate a planner package; export/print HTML while labels contain
  markup such as `<img src=x onerror=alert(1)>` (via poisoned workspace /
  hostile product/role/note strings).
- Expected: Markup encoded; no script execution in the print window.
- Actual: Title, zone, role, product name, style, and conceptual notes were
  interpolated raw into `document`/Blob HTML.
- Evidence: Source review vs already-safe `sales/documents.ts` and
  `analytics/export.ts`.
- Root cause: Missing output encoding on the planner-only export path.
- Fix: Local `escapeHtml` applied to all interpolated strings; download
  filename sanitized.
- Validation: Security unit encoding contract; security harness; web suite;
  production build.

**P3-D2 — CSV formula injection**

- Severity: Medium
- Component: `packages/web/src/marketing/cx/analytics/export.ts`
- Steps: Assign a salesperson label starting with `=`; export BI CSV; open in
  Excel/Sheets.
- Expected: Formula characters neutralized.
- Actual: `escapeCsv` only quoted commas/newlines.
- Fix: Prefix values matching `/^[=+\-@\t\r]/` with `'`.
- Validation: `rc108-security.test.ts`; analytics regression tests.

**P3-D3 — Production CSP localhost connect-src**

- Severity: Medium
- Component: `packages/web/index.html`, `packages/web/vite.config.ts`
- Steps: Inspect production `dist/index.html` CSP after `vite build`.
- Expected: `connect-src 'self'` (API is same-origin via reverse proxy).
- Actual: Shipped `http://127.0.0.1:8080`, `http://localhost:8080`, and Vite
  HMR websocket hosts.
- Fix: Production meta CSP uses `connect-src 'self'` only; the existing Vite
  HTML transform adds localhost/HMR hosts solely while `ctx.server` is active.
- Validation: Production build CSP inspection; security harness asserts no
  localhost in `index.html`.

### Verified clean

- Open redirect: `sanitizeReturnUrl` rejects `//`, `/\\`, absolute URLs, and
  `/login`; browser login with `returnUrl=//evil.example` stayed same-origin.
- No `dangerouslySetInnerHTML`, `eval`, or `new Function` in web/api sources.
- Sales quotation/order PDF helpers already escape HTML.
- Sync filesystem paths cannot traverse via `userId`.
