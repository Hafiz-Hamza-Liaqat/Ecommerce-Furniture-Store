# RC10.4 — Customer Timeline Report

Canonical activity history is stored in `afh.cx.sales.workspace.timeline`, keyed by opportunity and `customerKey` (email/name).

## Event examples

- Inquiry created / project linked
- Quote generated / revised / sent / viewed / accepted / rejected / expired
- Pipeline stage changed
- Order created / order status changed
- Production started / delivery completed
- Assignment changed
- Internal note added (title only — **note body never copied**)
- Document generated

Customer detail view lists chronological timeline for the customer across the opportunity.
