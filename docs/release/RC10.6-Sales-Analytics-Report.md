# RC10.6 — Sales Analytics Report

Tab: **Sales**.

## Insights

- Quotation acceptance rate
- Conversion funnel (pipeline stage counts)
- Salesperson performance (pipeline package value)
- Revenue by salesperson / product category / room type
- Top-selling configurations (order line names)
- Average approval hours (sent → accepted)
- Average negotiation duration (opportunity created → updated for negotiation+ stages)

Derived from quotes, opportunities, orders, and planner plans — business engines unchanged.
