# RC10.6 — Export Report

## Formats

| Format | Mechanism |
|---|---|
| CSV | Client-side Blob download (`exportBiReportCsv`) |
| PDF | Print window HTML → browser Print / Save as PDF (`exportBiReportPdf`) |
| Printable dashboard | `window.print()` with print CSS hiding filters/nav |

No Excel integration. No server-side report jobs.
