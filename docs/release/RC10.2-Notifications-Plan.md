# RC10.2 — Notifications & Communication (MVP Plan)

**Status:** In progress  
**Date:** 2026-07-21  
**Depends on:** RC10.1 committed · precedes frozen RC10.3

## Goal

Ship a durable CX notifications center so later phases (quotes, product changes, CRM) have a place to emit events — local-only until RC10.5.

## Reuse

- `packages/web/src/marketing/nav/notifications.ts` (`afh.cx.notifications`)
- MarketingShell account-menu preview
- Existing categories (quote / share / project / product / crm / system)

## MVP scope

1. Dedicated **Notifications** page (grouped list, unread filter, mark one/all, deep links)
2. Wire `pushNotification` from real CX actions (project share/save, quote ready, system)
3. Keep MarketingShell preview in sync
4. Tests + short release notes

## Out of scope

- Email / SMS / push delivery  
- Backend Event Bus / mark-read API  
- Dual-store merge with ERP `afh.web.notif.inbox` (thin adapter later if needed)  
- PlatformShell alerts  
- RC10.3 product-change emitters (hook ready via `pushNotification`)

## Stop rule

Typecheck, lint, tests, build → docs → review → commit. Do not start RC10.3.
