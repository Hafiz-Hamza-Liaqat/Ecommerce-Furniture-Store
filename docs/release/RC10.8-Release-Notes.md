## Summary

RC10.8 closes out the RC10 line by focusing on release readiness rather than
new product surface. It verifies every prior RC10 phase end-to-end, hardens
production hygiene (secrets, backups, DR docs), re-runs the full automated gate
matrix across all packages, fixes one API lint defect, adds a cross-phase smoke
test, and captures the current performance posture as an **open launch risk**.

No product feature scope was added. RC10.1–RC10.7 surfaces are unchanged and
continue to pass their own gates.

## What changed in RC10.8

### Verification & test additions
- **New `rc108` cross-phase smoke** exercising the key route of every RC10 phase
  (see Test Summary). All routes reachable.
- Playwright baseline re-run: **16/16 PASS**.
- RC10.5 dual-browser sync verification re-run to **PASS** after a test-harness
  fix (see Fixes).
- RC10.6 analytics audit re-run: **PASS** (all filters / export / read-only /
  responsive / no-console).

### Fixes
- **API lint defect** — `packages/api/src/routes/routes.ts:77` used an inline
  `import()` type expression. Replaced with a **type-only** `CxWorkspaceStore`
  import. Typecheck / lint / build / test re-run **PASS** (75 tests).
- **RC10.5 dual-browser harness** — dialog **Close** control rendered outside the
  viewport, causing an initial failure. Harness updated to perform a **DOM click**
  instead of a coordinate click; re-run **PASS**.
- **Authenticated accessibility** — Lighthouse found an unnamed user-menu
  trigger, label/name mismatches, insufficient KPI trend contrast, and 12px map
  targets. Localized ARIA/CSS fixes raised app shell Accessibility **88 → 96**
  and Workspace BI **95 → 100**.

### Production hygiene
- Root `.gitignore` now excludes runtime data: SQLite DBs, WAL/SHM, `cx-sync/`,
  `dam-objects/`, and `backups/`.
- `scripts/backup-sqlite.sh` now uses `sqlite3 .backup` when available and
  includes the `cx-sync/` and `dam-objects/` directories in the backup set.
- Operations docs expanded: `env.example`, `startup.md`, `backup-restore.md`,
  and `disaster-recovery.md`.
