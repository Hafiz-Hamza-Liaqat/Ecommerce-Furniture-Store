# RC10.4 — Quotation Workflow Report

## Statuses

Draft → Sent → Viewed → Accepted → Rejected → Expired

Timestamps recorded on each transition (`draftAt`, `sentAt`, `viewedAt`, `acceptedAt`, `rejectedAt`, `expiredAt`).

## Revision history

`createQuoteRevision` always appends a **new** quote row with incremented `revision` and optional `revisesQuoteId`. Prior revisions remain readable and are never overwritten.

Project-level `ProjectQuote` history (RC9.4 / RC10.3) remains separate; the sales layer mirrors new planner quotes as sales revisions.

## PDF

`openQuotationPdf` opens a print-ready quotation document and records a document timeline entry.
