# RC10.3 — Accessibility Report

**Status:** Implemented — awaiting manual review  
**Date:** 2026-07-21

## Dialog (ChangeProductDrawer)

- Panel: `role="dialog"` · `aria-modal="true"` · `aria-labelledby` → title
- Backdrop button: `aria-label="Close drawer"`
- **Escape** closes while open (`keydown` listener)

## Labels

| Control | Semantics |
|---------|-----------|
| Design prefs | `role="group"` aria-label “Design preferences”; each select labeled (Style / Color / Material / Collection + `aria-label`) |
| Variants | `role="group"` aria-label “Variants”; per-group `<label>` wrapping select |
| Wishlist / Compare | `aria-pressed` on toggle buttons |

## Touch targets

`.site-btn` uses `min-height: var(--brand-touch-min)` (44px touch minimum). Drawer and conceptual CTAs use `site-btn` variants.

## Manual checklist

- [ ] Tab order into drawer; Escape dismisses
- [ ] Screen reader announces dialog title and prefs/variant labels
- [ ] Primary actions meet ~44px hit area on mobile
