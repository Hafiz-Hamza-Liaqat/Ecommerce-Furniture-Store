# RC10.7 — Inventory Architecture

- **Status:** Implemented — awaiting manual acceptance (no commit)
- **Surface:** `/app/manufacturing/ops` (Manufacturing → Ops workspace)
- **Package:** `packages/web/src/marketing/cx/ops/`
- **Storage key:** `afh.cx.ops.workspace` (listed in RC10.5 `STATIC_SYNC_KEYS`)
- **Mount:** `ModuleApp` manufacturing route `ops` + nav entry in `manufacturing/definition.ts`

## Principles

1. Local CX manufacturing ops — parallel to ERP Inventory/Procurement/Manufacturing chrome.
2. Never mutates CRM, quotations, sales order workflow, planner, sync engine, or analytics engine.
3. Sales orders are **read-only** references for production planning (`listOrders` / `listSalesOrdersForProduction`).
4. Inventory invariant: on-hand ≥ 0, reserved ≥ 0, reserved ≤ on-hand (`assertNonNegative`).
5. Extension hooks (`OpsExtensionHooks`) reserved for barcode/QR/warehouses/invoices/cost/MRP/ERP — not implemented.

## Item model

| Field | Notes |
|---|---|
| SKU | Unique (case-insensitive); duplicates rejected |
| Category | furniture_product, raw_material, accessory, hardware, fabric, wood, glass, metal, packaging, foam, other |
| Description, unit | Free text / default `ea` |
| stockOnHand | Current stock |
| reserved | Allocated to open production jobs |
| available | `stockOnHand - reserved` |
| minStock | Low-stock when available ≤ min |
| supplierId | Optional link to supplier |
| unitCostPkr | Used for estimated valuation only |
| status | active / inactive / discontinued |
