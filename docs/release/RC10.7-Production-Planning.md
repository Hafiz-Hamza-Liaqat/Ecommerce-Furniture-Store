# RC10.7 — Production Planning

## Stages (independent of CRM)

Queued → Material Ready → In Production → Quality Check → Packaging → Ready → Dispatched → Delivered

CRM / sales order status is never written by ops services. Optional `salesOrderId` is a read-only reference.

## Job lifecycle

1. `createProductionJob` — allocates available stock, records shortages, sets `pendingProcurement` when short; stage `queued` if short else `material_ready`
2. `advanceProduction` — forward-only; entering `in_production` posts `production_consumption` (reduces on-hand and reserved)
3. `releaseJobMaterials` — only for `queued` / `material_ready`; posts `allocation_release`, clears allocated, returns to `queued`

## Allocation display

Each job shows required / allocated / shortage per BOM line.
