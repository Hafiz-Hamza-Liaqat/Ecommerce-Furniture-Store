## Defects found and fixed

### P5-D1 — Service worker broke cross-origin images on Firefox (Medium)

**Reproduction**

1. Open `/blog` (or another page embedding Unsplash CDN images) in Playwright Firefox.
2. Observe console error from `sw.js`:
   `Failed to load ‘https://images.unsplash.com/…’. A ServiceWorker intercepted the request and encountered an unexpected error.`

**Root cause**

`packages/web/public/sw.js` called `event.respondWith(...)` for every GET, including cross-origin URLs. Same-origin responses were cached; cross-origin failures returned `undefined` from `.catch(() => cached)`, which Firefox treats as a Service Worker fetch failure.

**Fix**

Skip interception for non-same-origin requests so the browser handles CDN images natively. Same-origin shell caching is unchanged. On network failure with no cache entry, rethrow instead of resolving `undefined`.

**Verification**

- Firefox `/blog` after SW update: zero ServiceWorker console errors.
- Full desktop-firefox profile: `130` routes / `14` interactions, `0` flags.

## Remaining browser-specific limitations

1. **Safari coverage** is Playwright WebKit on Windows, not native macOS Safari or a physical iPhone.
2. **Mobile coverage** uses Playwright device descriptors (Pixel 7 / iPhone 14), not hardware devices or Android/iOS WebViews.
3. **ERP list “Export”** remains the Phase 4-documented toast stub (“CSV export UI — file generation stays server-side”). Real client CSV download is verified on `/app/sales/analytics` (`Export CSV`).
4. **Sync chip** primary touch height is ~29 px (WCAG AA floor met; AAA 44 px not claimed).
5. **Dev-server noise** (Vite HMR websocket, React DevTools banner, Firefox layout/font advisories) is allowlisted and is not production runtime behavior.
