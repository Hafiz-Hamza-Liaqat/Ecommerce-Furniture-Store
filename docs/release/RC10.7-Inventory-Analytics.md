# RC10.7 — Inventory Analytics

## Surface

Ops workspace **Analytics** tab. Reuses RC10.6 `BiWidgets` (`BiKpiGrid`, `BiBarPanel`, `BiDonutPanel`) by import only — does **not** modify `derive.ts` / BI engine.

## Derive (`computeOpsAnalytics`)

| Metric | Source |
|---|---|
| Low stock | available ≤ minStock |
| Inventory valuation (est.) | Σ stockOnHand × unitCostPkr |
| Fast-moving | |qty| from purchase_received + production_consumption |
| Slow-moving | on-hand > 0 with no such movements |
| Material shortages | open job allocation shortages |
| Supplier open POs | non-closed procurements per supplier |
| Procurement by stage | counts |
| Production by stage | counts |
| Production backlog | jobs not dispatched/delivered |
