# RC10.4 — Orders Report

## Creation

Orders are created only from **accepted** sales quotations via `createOrderFromAcceptedQuote`.

Each order includes:

- Order ID, customer, linked project (optional), quote id
- Configured package snapshot (lines, variants when present, pricing)
- Tax slot (`taxPkr = 0`, future-ready)
- Delivery status & payment status
- Created / updated timestamps
- Assigned salesperson label (from opportunity assignments)

## Status lifecycle

Draft → Awaiting Approval → Approved → In Production → Ready for Delivery → Delivered → Completed (or Cancelled)

`setOrderStatus` updates order + CRM pipeline stage only. **Planner package data is never mutated.**

## Documents

- Order PDF (print HTML)
- Invoice placeholder (no accounting)
- Delivery note placeholder
